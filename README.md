# 番茄酱存档 / Ketchup Archive

一个中文母语者在全世界收集麦当劳番茄酱包的个人档案。

番茄酱是全球化最无聊的证明。这个项目用工整的方式对待一个被忽视的小东西。缺席的收藏和存在的收藏一样重要。

**线上访问：** https://tangerinecamel.github.io/ketchup-archive

---

A personal archive of McDonald's ketchup packets collected around the world.

Ketchup is one of the most extreme products of industrialization and globalization. Nobody documents it seriously. This project treats a neglected little thing with care. The absent collection matters as much as the present one.

**Live site:** https://tangerinecamel.github.io/ketchup-archive
